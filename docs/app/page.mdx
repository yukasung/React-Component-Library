# React Component Library

Docs for the internal React Component Library — reusable React + TypeScript
components styled with Tailwind CSS.

## Components

- [**InputNumber**](/components/input-number) — input ที่ให้ผู้ใช้กรอกและแก้ไข
  ได้เฉพาะตัวเลขเท่านั้น ค่าที่กรอกสามารถจัดรูปแบบหรือจำกัดให้อยู่ในช่วงที่กำหนดได้
- [**InputDate**](/components/input-date) — input สำหรับกรอกวันที่
  รองรับทั้งการพิมพ์ข้อความและเลือกจากปฏิทินแบบ dropdown จำกัดช่วงวันที่
  ต่ำสุด/สูงสุด (min/max) และการจัดรูปแบบวันที่ (format)
- [**InputTime**](/components/input-time) — input สำหรับกรอกเวลา
  รองรับทั้งการพิมพ์ข้อความและเลือกจากรายการเวลาแบบ dropdown ที่สร้างตาม
  ช่วงเวลาต่ำสุด/สูงสุด (min/max) และระยะห่างเป็นนาที (step)
  พร้อมการจัดรูปแบบเวลาทั้งแบบ 24 และ 12 ชั่วโมง (format)
