# React Component Library

Docs for the internal React Component Library — reusable React + TypeScript
components styled with Tailwind CSS.

## Components

- [**InputNumber**](/components/input-number) — input สำหรับกรอกและแก้ไข
  ตัวเลขเท่านั้น กำหนดรูปแบบการแสดงผลหรือจำกัดช่วงค่าที่กรอกได้
- [**InputDate**](/components/input-date) — input สำหรับกรอกและแก้ไขวันที่
  พร้อมปฏิทินแบบ dropdown ให้เลือกได้
- [**InputTime**](/components/input-time) — input สำหรับกรอกและแก้ไขเวลา
  พร้อมรายการเวลาแบบ dropdown ให้เลือกได้
- [**InputDateTime**](/components/input-date-time) — input สำหรับกรอกและแก้ไข
  วันที่และเวลาในช่องเดียวกัน พร้อม dropdown สองแบบ คือปฏิทินสำหรับวันที่
  และรายการเวลาสำหรับเวลา
- [**InputTag**](/components/input-tag) — input สำหรับเลือกหลาย tag แสดงค่าเป็น
  chip และรองรับการเพิ่ม tag แบบกำหนดเอง
