# InputMask

InputMask คือ input สำหรับกรอกข้อมูลที่มีรูปแบบตายตัว โดยจำกัดให้พิมพ์ได้เฉพาะอักขระที่รูปแบบนั้นยอมรับ และวางตัวคั่นให้เอง

<DefaultDemo />

## Import

```tsx
import { InputMask } from '@yukasung/react-components'
```

## Properties

<PropertyIndex />

### mask

<PropertySignature name="mask" type="string" />

กำหนดรูปแบบของข้อมูล แต่ละอักขระในรูปแบบคือหนึ่งตำแหน่งที่ผู้ใช้กรอกได้ ส่วนอักขระอื่นเป็นตัวคั่นที่ control วางให้เอง

| อักขระ | รับ | บังคับกรอก |
| --- | --- | --- |
| `0` | ตัวเลข | ใช่ |
| `9` | ตัวเลข หรือเว้นว่าง | ไม่ |
| `#` | ตัวเลข เครื่องหมาย `+` `-` หรือเว้นว่าง | ไม่ |
| `L` | ตัวอักษร | ใช่ |
| `l` | ตัวอักษร หรือเว้นว่าง | ไม่ |
| `A` | ตัวอักษรหรือตัวเลข | ใช่ |
| `a` | ตัวอักษรหรือตัวเลข หรือเว้นว่าง | ไม่ |

นอกจากนี้ `\` ทำให้อักขระถัดไปกลายเป็นตัวคั่นธรรมดา (เช่น `00\000` มีเลข `0` เป็นตัวคั่นอยู่ตรงกลาง) ส่วน `>` บังคับตัวอักษรที่ตามมาให้เป็นพิมพ์ใหญ่ `<` เป็นพิมพ์เล็ก และ `|` ยกเลิกการบังคับ

<MaskDemo />

```tsx
<InputMask mask="0-0000-00000-00-0" />
<InputMask mask="00000" />
```

<Callout type="info">
  **ความกว้างคงที่เสมอ**

  จำนวนตำแหน่งไม่เปลี่ยนตามสิ่งที่พิมพ์ ข้อมูลที่ความยาวไม่แน่นอนเขียนด้วยอักขระที่ไม่บังคับกรอก (`9` `#` `l` `a`) ซึ่งปล่อยว่างได้ — ดู [ตำแหน่งที่ไม่บังคับกรอก](#ตำแหน่งที่ไม่บังคับกรอก)
</Callout>

### value

<PropertySignature name="value" type="string | null" />

กำหนดค่าปัจจุบันของ control **ค่านี้ไม่มีตัวคั่นอยู่ในนั้น** — มีเฉพาะอักขระที่ผู้ใช้กรอก เรียงตามตำแหน่ง

<ValueDemo />

```tsx
const [value, setValue] = useState<string | null>('0812345678')
<InputMask mask="000-000-0000" value={value} onChange={setValue} />
// แสดง    081-234-5678
// ค่าคือ  "0812345678"
```

<Callout type="info">
  **Note**

  ค่าจะถูกประมวลผลและยิง `onChange` เฉพาะตอนออกจากฟิลด์ (blur) หรือกด Enter เท่านั้น ไม่ใช่ทุกครั้งที่พิมพ์
</Callout>

#### ตำแหน่งที่ไม่บังคับกรอก

ตำแหน่งที่ไม่บังคับกรอกและถูกปล่อยว่างจะกลายเป็น **ช่องว่าง** ในค่า ไม่ได้หายไป เพราะตำแหน่งมีความหมาย — `"1 23"` กับ `" 123"` เป็นคนละค่ากันสำหรับ mask `99-00`

<OptionalDemo />

```tsx
<InputMask mask="(999) 000-0000" value={value} onChange={setValue} />
// แสดง    (02_) 555-1234
// ค่าคือ  "02 5551234"
```

ถ้าโดเมนของคุณไม่ต้องการช่องว่างเหล่านั้น ให้ตัดออกเองตอนประกอบข้อมูลส่ง backend เพราะ control ไม่รู้ว่าช่องว่างนั้นมีความหมายหรือไม่

```tsx
const raw = value?.replace(/ /g, '') ?? null
```

#### ตัวอักษรและภาษาไทย

`L` และ `A` รับตัวอักษรทุกภาษา หนึ่งตำแหน่งเก็บหนึ่งอักขระที่มองเห็น ดังนั้นสระและวรรณยุกต์จะเกาะไปกับพยัญชนะตัวหน้าโดยไม่กินตำแหน่งเพิ่ม

<ThaiDemo />

ส่วน `0` `9` `#` รับเฉพาะเลขอารบิก `0`-`9` เท่านั้น เพราะเป็นตำแหน่งสำหรับตัวเลขในรหัส ซึ่งระบบปลายทางเก็บเป็น ASCII

<Callout type="warning">
  **สระนำหน้านับเป็นคนละตำแหน่ง**

  `เ` `แ` `โ` `ไ` `ใ` เป็นพยัญชนะฐานในตัวเอง คำว่า `เกี๊ยว` จึงกิน 4 ตำแหน่ง (`เ` `กี๊` `ย` `ว`) mask นับอักขระ ไม่ได้นับพยางค์
</Callout>

### defaultValue

<PropertySignature name="defaultValue" type="string | null" />

กำหนดค่าเริ่มต้นสำหรับการใช้งานแบบ uncontrolled คือปล่อยให้ control เก็บค่าเอง ไม่ต้องส่ง `value` กลับเข้ามา

```tsx
<InputMask mask="000-000-0000" defaultValue="0812345678" />
```

### onChange

<PropertySignature name="onChange" type="(value: string | null) => void" />

เรียกเมื่อค่าถูก commit โดยได้รับค่าที่ไม่มีตัวคั่น ไม่ใช่ event

จะถูกเรียกก็ต่อเมื่อตำแหน่งที่บังคับกรอกครบทุกตำแหน่ง หรือเมื่อฟิลด์ถูกล้างจนว่างและ `isRequired` เป็น `false` (ได้ `null`) ถ้ากรอกไม่ครบ ฟิลด์จะกลับไปเป็นค่าเดิมโดยไม่เรียก callback

### promptChar

<PropertySignature name="promptChar" type="string" />

กำหนดอักขระที่แสดงแทนตำแหน่งที่ยังไม่ได้กรอก ค่าเริ่มต้นคือ `_`

<PromptCharDemo />

```tsx
<InputMask mask="00/00" promptChar="•" />
```

<Callout type="info">
  **Note**

  ถ้าอักขระที่ส่งมาเป็นอักขระที่ mask นั้นรับเป็นข้อมูลได้อยู่แล้ว (เช่น `promptChar="0"` กับ mask `00`) จะถูกปฏิเสธและกลับไปใช้ `_` เพราะจะแยกไม่ออกว่าตำแหน่งนั้นกรอกแล้วหรือยัง
</Callout>

### placeholder

<PropertySignature name="placeholder" type="string" />

กำหนดข้อความที่แสดงเมื่อ control ว่างเปล่า ถ้าไม่ระบุจะแสดงรูปร่างของ mask เอง เช่น `___-___-____` จึงบอกผู้ใช้ได้ว่าช่องนี้รอข้อมูลรูปแบบไหนโดยไม่ต้องเขียนเอง

<PlaceholderDemo />

### overwriteMode

<PropertySignature name="overwriteMode" type="boolean" />

กำหนดว่าการพิมพ์ทับตำแหน่งที่มีข้อมูลอยู่แล้วจะเขียนทับ หรือแทรกแล้วดันตัวที่เหลือไปทางขวา ค่าเริ่มต้น `false` คือแทรก

<OverwriteModeDemo />

```tsx
<InputMask mask="000-000" overwriteMode />
```

<Callout type="info">
  **Note**

  โหมดแทรกจะไม่ทิ้งตัวท้ายเพื่อให้มีที่ว่าง ถ้าไม่มีตำแหน่งว่างเหลืออยู่ทางขวาของ caret การพิมพ์นั้นจะถูกปฏิเสธ
</Callout>

### text

<PropertySignature name="text" type="string" />

ผูกข้อความที่แสดงในฟิลด์แบบสองทาง แยกจาก `value` ซึ่งเก็บค่าที่ไม่มีตัวคั่น ใช้คู่กับ `onTextChange` ที่ถูกเรียกทุกครั้งที่ข้อความบนหน้าจอเปลี่ยน

<TextDemo />

```tsx
<InputMask mask="000-000-0000" value={value} onChange={setValue} onTextChange={setText} />
```

<Callout type="warning">
  **ข้อความที่ส่งเข้ามาจะถูกอ่านผ่าน mask ก่อนเสมอ**

  ไม่ได้ถูกเขียนลงไปตรง ๆ อักขระที่ mask ไม่รับจะถูกทิ้ง เช่น mask `00` กับ `text="AB"` จะได้ฟิลด์ว่าง ไม่ใช่ `AB` เพราะข้อความบนหน้าจอต้องเป็นรูปแบบที่ mask อธิบายได้เสมอ มิฉะนั้นจะหาค่าจากมันไม่ได้
</Callout>

### onInvalidInput

<PropertySignature name="onInvalidInput" type="(info: InvalidInputInfo) => void" />

เรียกเมื่อการกรอกถูกปฏิเสธ ใช้เพื่อแจ้งผู้ใช้ เช่น ทำให้ฟิลด์กะพริบหรือขึ้นข้อความ

<OnInvalidInputDemo />

```tsx
<InputMask mask="000-000" onInvalidInput={(info) => console.log(info.reason)} />
```

`info.reason` บอกสาเหตุ

| ค่า | เมื่อ |
| --- | --- |
| `'character'` | อักขระที่พิมพ์ไม่ตรงกับตำแหน่งนั้น |
| `'full'` | ไม่มีตำแหน่งเหลือให้รับอักขระนั้น |
| `'paste'` | วางข้อความแล้วมีบางส่วนถูกทิ้ง เรียกครั้งเดียวต่อการวางหนึ่งครั้ง |
| `'incomplete'` | ออกจากฟิลด์ทั้งที่ยังกรอกไม่ครบ |

นอกจากนี้ยังมี `info.input` คืออักขระหรือข้อความที่ถูกปฏิเสธ และ `info.position` คือตำแหน่งที่ปฏิเสธ

<Callout type="info">
  **เป็นการแจ้งเท่านั้น**

  ยกเลิกไม่ได้ อักขระที่ถูกปฏิเสธจะไม่ปรากฏในฟิลด์เสมอ เพราะข้อความบนหน้าจอต้องเป็นรูปแบบที่ mask อธิบายได้ตลอดเวลา
</Callout>

### isRequired

<PropertySignature name="isRequired" type="boolean" />

กำหนดว่าฟิลด์นี้ต้องมีค่า ค่าเริ่มต้นคือ `true`

เมื่อเป็น `true` การล้างฟิลด์จนว่างแล้วออกจากฟิลด์จะทำให้ค่าเดิมกลับมา แทนที่จะ commit ค่าว่าง (ถ้าไม่เคยมีค่าเดิมเลย ฟิลด์จะยังว่างอยู่ ไม่มีการสร้างค่าขึ้นมาแทน)

<IsRequiredDemo />

```tsx
<InputMask mask="000-000" isRequired={false} />
```

### เมื่อไม่ระบุ mask

ถ้าไม่ส่ง `mask` มาเลย หรือ mask นั้นไม่มีตำแหน่งให้กรอก control จะกลายเป็นช่องข้อความธรรมดา ไม่มีการปฏิเสธอักขระใด ไม่มีตัวคั่น และค่าที่ commit คือข้อความตามที่พิมพ์ทุกประการ

<NoMaskDemo />

## การใช้งานกับฟอร์ม

`name` จะส่ง **ข้อความที่แสดง** ไปกับฟอร์ม ไม่ใช่ค่าที่ commit ซึ่งเป็นพฤติกรรมเดียวกับ input ตัวอื่นในไลบรารีนี้

```tsx
<InputMask mask="000-000-0000" name="phone" value={value} onChange={setValue} />
// new FormData(form).get('phone') → "081-234-5678"
// value                          → "0812345678"
```

ถ้าต้องการส่งค่าที่ไม่มีตัวคั่นไปยัง backend ให้ประกอบข้อมูลจากค่าที่ได้จาก `onChange` แทนการอ่านจาก `FormData`

## แป้นพิมพ์

| ปุ่ม | ผล |
| --- | --- |
| ลูกศรซ้าย/ขวา | ย้ายทีละตำแหน่ง |
| Home | ไปตำแหน่งแรก |
| End | ไปท้ายฟิลด์ |
| Backspace / Delete | ล้างตำแหน่งก่อนหน้า / ตำแหน่งปัจจุบัน ไม่ลบตัวคั่น |
| Enter | commit ค่า |
| Escape | ย้อนกลับเป็นค่าที่ commit ไว้ล่าสุด |
| Tab | ออกจากฟิลด์ตามลำดับปกติของฟอร์ม |

การพิมพ์ตัวคั่นตามรูปแบบทำได้ตามปกติ เช่น mask `000-000-0000` พิมพ์ `081-234-5678` รวดเดียวได้เลย ตัวขีดที่พิมพ์จะถูกรับไว้เฉย ๆ เพราะ control ข้ามไปให้แล้ว

การคัดลอกจะได้ข้อความที่เห็นบนหน้าจอ และการวางข้อความนั้นกลับเข้าไปจะได้ค่าเดิมทุกตำแหน่ง ส่วนการวางค่าที่ไม่มีตัวคั่น เช่น `0812345678` ก็ใช้ได้เช่นกัน
