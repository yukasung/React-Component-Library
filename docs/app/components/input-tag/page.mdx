# InputTag

InputTag คือ input สำหรับเลือกหลาย tag จากรายการ แสดงค่าที่เลือกเป็น chip ที่ลบได้ และเปิดให้ผู้ใช้เพิ่ม tag แบบกำหนดเองได้เมื่อจำเป็น

<DefaultDemo />

## Import

```tsx
import { InputTag } from '@yukasung/react-components/input-tag'
```

นำ stylesheet ของ package เข้า application entry point หนึ่งครั้ง:

```tsx
import '@yukasung/react-components/style.css'
```

## Properties

<PropertyIndex />

### id

<PropertySignature name="id" type="string" />

กำหนด id ของ combobox ถ้าไม่ระบุ component จะสร้าง id ให้เอง

### ariaLabel

<PropertySignature name="ariaLabel" type="string" />

ชื่อที่ accessibility API ใช้กับ combobox และ listbox ต้องระบุทุกครั้ง

### options

<PropertySignature name="options" type="readonly string[]" />

รายการ tag ที่ผู้ใช้เลือกได้

### value

<PropertySignature name="value" type="readonly string[]" />

ค่าปัจจุบันสำหรับ controlled mode ใช้คู่กับ `onChange`

### defaultValue

<PropertySignature name="defaultValue" type="readonly string[]" />

ค่าเริ่มต้นสำหรับ uncontrolled mode ค่าเริ่มต้นคือ `[]`

### onChange

<PropertySignature name="onChange" type="(value: readonly string[]) => void" />

เรียกเมื่อมีการเลือก ลบ หรือเพิ่ม tag

### placeholder

<PropertySignature name="placeholder" type="string" />

ข้อความที่แสดงเมื่อยังไม่มี tag ที่เลือก ค่าเริ่มต้นคือ `Select options`

### isDisabled

<PropertySignature name="isDisabled" type="boolean" />

ปิดการเปิด dropdown และการลบ tag ค่าเริ่มต้นคือ `false`

<DisabledDemo />

### portal

<PropertySignature name="portal" type="boolean" />

ย้าย dropdown ไปไว้ใต้ `document.body` เพื่อไม่ให้ถูกตัดโดย popover พร้อมปรับตำแหน่งเมื่อ input เปลี่ยนความสูง scroll หรือ resize ค่าเริ่มต้นคือ `false`

### className

<PropertySignature name="className" type="string" />

class เพิ่มเติมสำหรับพื้นผิว input ที่มีกรอบ

### removeLabel

<PropertySignature name="removeLabel" type="(tag: string) => string" />

สร้าง ARIA label สำหรับปุ่มลบแต่ละ chip

### addCustomTag

<PropertySignature name="addCustomTag" type="{ ariaLabel: string; placeholder: string }" />

เปิด text input ใน dropdown ผู้ใช้พิมพ์แล้วกด Enter เพื่อเพิ่ม tag ใหม่ ค่าใหม่จะถูก trim และไม่เพิ่มค่าว่างหรือค่าซ้ำโดยไม่สนตัวพิมพ์

### name

<PropertySignature name="name" type="string" />

ส่งค่าผ่าน hidden input หนึ่งรายการต่อ tag อ่านค่าด้วย `new FormData(form).getAll('tags')`
เมื่อกำหนด `name="tags"` ค่าว่างไม่ส่งรายการใด และ `isDisabled` ไม่นำค่ารวมในการ submit

### ref

<PropertySignature name="ref" type="React.Ref<HTMLDivElement>" />

รองรับ object ref และ callback ref โดยชี้ไปที่ combobox ที่ focus ได้
ใช้ `ref.current?.focus()` เพื่อเลื่อนไปยังฟิลด์ที่มี validation error

### onBlur

<PropertySignature name="onBlur" type="React.FocusEventHandler<HTMLDivElement>" />

เรียกเมื่อ focus ออกจากทั้งฟิลด์ รวมเมนูแบบ portal การย้าย focus ไปปุ่มลบหรือช่องเพิ่ม tag
ภายในไม่ทำให้ฟิลด์ touched เมื่อออกด้วย Tab หรือ Shift+Tab เมนูจะปิดและ focus อยู่ที่ปลายทาง
`event.currentTarget` คือ root ของฟิลด์ ไม่ใช่ combobox ที่ `ref` ชี้ไป

### isReadOnly

<PropertySignature name="isReadOnly" type="boolean" />

ค่าเริ่มต้น `false` เมื่อเปิดใช้ จะเปิดเมนู เพิ่ม หรือลบ tag ไม่ได้
combobox ยัง focus ได้ และค่าที่เลือกยังส่งผ่าน `name` ได้ การอัปเดต controlled value จาก parent ยังทำงาน

### isRequired

<PropertySignature name="isRequired" type="boolean" />

ค่าเริ่มต้น `false` กำหนด `aria-required` เพื่อประกาศสถานะเท่านั้น
ไม่ได้ใช้ native required validation: ฟอร์มต้องตรวจ array ที่เลือกเอง

### Validation ARIA

รองรับ `aria-invalid`, `aria-describedby`, `aria-errormessage` และ `aria-labelledby`
บน combobox เพื่อเชื่อม label และข้อความผิดพลาด โดยยังต้องส่ง `ariaLabel` และ `removeLabel`
ตาม API เดิม ตัวอย่างฟอร์มที่เป็นเจ้าของ validation:

```tsx
import { useRef, useState } from 'react'
import { InputTag } from '@yukasung/react-components/input-tag'

function TagField() {
  const ref = useRef<HTMLDivElement>(null)
  const [tags, setTags] = useState<readonly string[]>([])
  const [touched, setTouched] = useState(false)
  const invalid = touched && tags.length === 0
  return <>
    <InputTag ref={ref} name="tags" ariaLabel="Tags"
      options={['Important', 'Urgent']} value={tags} onChange={setTags}
      removeLabel={tag => `Remove ${tag}`} isRequired
      onBlur={() => setTouched(true)} aria-invalid={invalid}
      aria-describedby={invalid ? 'tags-error' : undefined} />
    {invalid && <p id="tags-error">Select at least one tag.</p>}
  </>
}
```
